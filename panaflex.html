WorkflowGenie — AI-Powered Office Automation

Automating Excel & Data Operations via Natural Language  |  Large Language Models  |  Retrieval-Augmented Generation

FYP 2025–26

An intelligent web application that lets users control spreadsheets using plain English commands — powered by Large Language Models, 91 specialized tools, 106+ Excel-compatible formulas, and a built-in RAG engine for document-aware Q&A.

Motivation

  • Knowledge workers spend over 2 hours/day on repetitive spreadsheet tasks.
  • Non-technical users struggle with Excel formulas, pivot tables, and charts.
  • AI breakthroughs in LLMs now enable natural language → operation translation.
  • Existing tools lack deep Excel integration with real-time AI reasoning.
  • WorkflowGenie eliminates the skill barrier and speeds up data workflows by 10×.

Generative AI Usage Statement

AI tools were used for limited assistance in brainstorming, documentation refinement, complex syntax resolution, and diagram enhancement. All implementation, analysis, and conclusions were carried out independently by the group members.

Challenges

  • Translating ambiguous natural language into precise Excel operations.
  • Managing multi-sheet context across large workbooks accurately.
  • Building a reliable 91-tool pipeline — including an auto-dashboard generator — that handles edge cases gracefully.
  • Generating correct formulas for 106+ Excel functions on demand.
  • Ensuring RAG retrieval accuracy across diverse spreadsheet schemas.
  • Achieving low-latency AI responses within the 30-second timeout.
